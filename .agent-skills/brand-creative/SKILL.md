# Medus Brand / Creative

Use the latest user-approved project style as the primary source of truth. Never import Anthropic brand colors, fonts, or identity into Medus.

For Medus, prioritize medical credibility, modern information hierarchy, low clutter, and clear educational structure for medical learners/professionals.

For Bác Sĩ Cảnh Báo, prioritize mobile-first short-form communication, a strong hook, immediate readability, controlled sensationalism, and medical accuracy. Preserve established O/stickman rules when relevant.

Before designing, define the audience, platform/aspect ratio, primary message, and one dominant visual idea.

Avoid decorative elements that do not improve understanding. Optimize copy for the time the viewer realistically has to read it.

When a new creative is approved by the user as a reference style, treat its repeatable characteristics as candidate rules for future assets while preserving explicit project constraints.
